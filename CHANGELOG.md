# Changelog

## 0.1.0 — 2026-10-08

Initial open beta:
- Local-first CSV, TSV and JSON tabular import and conversion.
- Column type inference, missing-value and exact-duplicate checks.
- Whitespace cleanup, empty-row removal, deduplication and header normalisation.
- CSV/TSV/JSON export with basic spreadsheet-formula safeguards, plus Markdown quality report output.
- JSON validation, formatting and minification.
- Responsive marketing website, guide and privacy information.
- Cloudflare Workers static-asset deployment and CI tests.
